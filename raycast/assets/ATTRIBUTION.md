# WezTerm icon attribution

`wezterm.png` is a 512 × 512 PNG conversion of the official WezTerm macOS icon, with alpha transparency and original padding preserved.

- Project: https://github.com/wezterm/wezterm
- Source: https://github.com/wezterm/wezterm/blob/c7f4b081a685ab71eef6571b4050af061fff9c85/assets/macos/WezTerm.app/Contents/Resources/terminal.icns
- Upstream source Git blob: `0ba8eef32d25be1a898d35256949a424e0c3ccc9`
- SVG original: `assets/icon/wezterm-icon.svg` (metadata credits Wez Furlong)
- Obtained from the installed WezTerm app; its ICNS Git blob hash was verified equal to the pinned upstream asset.
- PNG SHA-256: `667169edc4d4d5ef3b75cc3cec2a58e8ea4214bc0ba450714b531b73508b9e2e`
- Conversion: `sips -s format png terminal.icns --resampleHeightWidth 512 512 --out wezterm.png`
